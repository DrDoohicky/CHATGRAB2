## Changes

- `/founding/`: proposed $19 USD one-time offer, exact present-release scope and limitations. Checkout is disabled. An explicitly mocked modal exercises completion, error, cancellation and retry without requests, orders, storage or entitlements.
- `/privacy/` and `/terms/`: browser-local storage, data transfers, backup/deletion steps, independent-product disclosure, current free-use terms and clearly draft future commercial/refund terms. No customer sale is offered. Docket review and a private commercial support channel remain prerequisites for any later paid launch.
- Workspace notice links to the offer and privacy page and warns about shared browser profiles. The connection panel accurately says native sign-in and automated inference are unavailable.
- Added native text-only ChatGPT `conversations.json` imports. Traverse `current_node` back to the root, preserve speaker/text and selected branch, reject broken/circular chains and unsupported non-text content rather than silently losing it. Existing backup restore and collision behavior remain.
- Local import file limit: 15 MB. Storage errors are visible; unreadable stored libraries are preserved until explicit reset. Failed imports preserve existing records.
- Share fetching enforces HTTPS, bounded redirects only to supported public ChatGPT share paths, a 15-second deadline and 8 MB response cap.
- Fixed mobile header overflow and local static directory routing. Added a dependency lockfile and repeatable test scripts.

### Repeat the browser checks

`npm ci`, `npm run build`, then `PORT=3001 npm start`. In another shell run `BASE_URL=http://127.0.0.1:3001 CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`. If using Playwright's managed browser, install Chromium with `npx playwright install chromium` and omit `CHROMIUM_PATH`. Test outputs go under ignored `evidence/launch/` unless `EVIDENCE_DIR` is supplied. Tests use disposable browser contexts, never an existing user's profile.

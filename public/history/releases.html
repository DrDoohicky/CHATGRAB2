What’s new in ChatGrab.

November 19, 2026 · Direct share import and clearer screens

  • The ChatGPT share-link field is visible on Import Source. Public pages are requested as web documents rather than generic background resources; fetched messages must be reviewed before saving.
  • If a public share returns only a preview, the recovery steps open the original and import copied text with its source link attached. This never claims to retrieve unavailable messages or attachments.
  • Review & Analyze explains the handoff to your own ChatGPT account. Export & Recover separates ChatGrab backup from OpenAI account-data exports. Direct ZIP import remains in development; unzip and choose conversations.json.
  • Version: LIVE / LOCAL / REVIEW opens a chosen build in a new tab, keeping libraries and drafts separate. Configure your PC’s LAN address on phones; local processes cannot be started remotely. Review may require sign-in.

Your existing library and original branding remain unchanged. No paid AI key, private-chat access, synchronized accounts, or automatic in-app AI service is activated.

November 18, 2026 · A clearer path through your work

  • One main Import source action opens the reviewed file/paste chooser. Share-link, batch and artifact options remain available under Other intake options.
  • Import → Review → Analyze → Export navigation shows the current stage and a useful next action. The source you just reviewed is selected for analysis.
  • Storage information is shorter, with a visible Export backup action. Your original source and files remain browser-local; keep a backup before clearing browser data.
  • The assistant launcher stays in document flow on compact screens so it does not cover fields or buttons. Keyboard access and Escape remain available.
  • Empty libraries get a short starting instruction; populated libraries keep their source cards and review tools.

ChatGPT interpretation uses your own account through a reviewed request. This release does not activate automatic private-chat capture, cloud synchronization, or in-app AI replies.

November 18, 2026 · Source-preserving analysis and history

Continuity capsules keep their original JSON and show reconstructed events separately from original chat turns. Review consent is beside Copy request, with a selectable-text fallback when copying is blocked. Returned reviews retain the exact source/request/response, survive reload and are included in complete backups.

Visual history adds real dated build screenshots, distinct app/Vercel/GitHub controls, and a named side-by-side comparison. Protected or retired builds have explicit access labels.

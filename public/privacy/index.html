Privacy & data controls

Current release · November 8, 2026. ChatGrab is operated by David R. Labadie. This page describes the current browser-local release, not a future hosted account service.

Where your data lives

Conversation records are saved in localStorage in your browser profile. Supporting files are stored in IndexedDB on the same device. They are not encrypted by ChatGrab or isolated by a ChatGrab account. People using the same browser profile may access them. Use separate browser profiles on shared devices and avoid importing sensitive information.

What leaves your browser

  • File imports and the “Import copied text” control process your selected text locally. They do not upload transcripts to a ChatGrab library server.
  • Public-share capture sends the URL to the ChatGrab server, which requests that public ChatGPT page and returns its transcript. Server fetching and transient processing are required for this path. Some older modal controls send pasted transcript text to this capture API for parsing; use the main page’s local import controls to avoid that transfer.
  • Manual analysis lets you select and copy text into ChatGPT or another service yourself. That service’s terms then apply. Native ChatGPT sign-in and automated analysis are unavailable.
  • The existing source-search API processes the query and source excerpts you submit to it. It does not provide cloud backup.
  • Hosting providers process ordinary request metadata such as IP addresses, URLs, browser information and operational logs. Do not put private text in URLs. We do not promise that hosting infrastructure retains no logs.

Backups, deletion and retention

Export a library JSON backup before changing browsers or clearing storage. Deleting a conversation removes it from the current local library; it does not erase downloaded exports or separately stored attached files. To erase all ChatGrab data, use your browser’s site-data controls for this domain to clear localStorage and IndexedDB. This also removes attached files and saved preferences. We do not retain a server copy of this browser-local library to restore it for you.

Browser quota limits, private browsing, device failure and clearing site data may remove your records. A successful save is not a permanent backup. Download attached originals separately.

Accounts and payments

No cloud account or paid membership is offered in this launch. There are no card forms, payment-provider requests or payment receipts. If account storage or payment processing is introduced later, its data practices and terms must be disclosed before use.

Your content and contact

You retain your rights in imported content. Import only material you own or have permission to use. For product and privacy questions, open a repository issue. Issues are public: never include transcripts, passwords, payment information or other private details.

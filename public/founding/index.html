A practical start for your conversation library.

Bring your text

Import copied text, TXT/Markdown, ChatGrab JSON backups and text-only ChatGPT JSON exports. Public-share capture can be blocked by ChatGPT; file and text imports are the reliable fallback.

Organize and revisit

Keep conversations in this browser, search your library and source text, rename records and prepare manual analysis prompts for use in your own ChatGPT session.

Take a copy

Download library JSON and conversation Markdown/JSON. Use your browser’s print dialog for PDF. Attached file originals need separate downloads from Artifacts.

Know the limits before you start.

Conversations and attached files stay in this browser profile. They do not sync across devices. Anyone using the same profile can access them. Clearing site data can erase them, so keep exported backups.

Native ChatGPT sign-in, automated AI analysis, hosted worker execution and paid membership are unavailable. ChatGrab is an independent tool; it is not affiliated with or endorsed by OpenAI.

Before a paid launch

What would the $19 cover?

The proposed offer covers personal use of this release’s browser-local import, library, manual-analysis preparation and export tools. It does not buy ChatGPT access, AI credits, cloud storage, future upgrades or a lifetime hosting guarantee. Final sales terms will need to be approved and shown before any payment is enabled.

Can I purchase or reserve a membership now?

No. Payments are disabled. The demo creates no order, receipt, account, reservation or membership. You can try the current workspace without paying.

What happens to my conversations?

File imports and copied-text imports run in your browser. Public-share capture sends the URL to the ChatGrab server to fetch that public page. Optional manual analysis involves copying selected text to a service you choose. See the privacy page for the distinction.

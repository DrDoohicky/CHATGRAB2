Source excerpts can be categorized as decision, constraint, correction or background, with an optional reason for including each. These user notes appear separately in the draft and exported Markdown, are stored on copied messages in the new continuity record, survive existing JSON/complete backup paths, and are restored when preparing a reviewed revision. Original messages are unchanged. Existing destination, conflict-review and explicit confirmation gates remain.

Packet annotations are optional, bounded to 2,000 rationale characters, and validated during conversation import. Legacy records still work. Tests cover exact source/role/blank-line retention, user-note separation, invalid annotations and collision reference remapping. No model requests, account integration or provider-specific dependencies were added.

The three interactive CSS design concepts are prototypes/chatgrab-floating-tiles/index.html: Floating Slate, Soft Porcelain and Precision Tiles. They use white rounded tiles, restrained elevation/shadows, heavier readable text, small colored CSS dimensional accents and reduced-motion support. They contain illustrative data and preview controls, not actual product state. These style concepts are separate from the integrated functional packet changes; selecting one remains David's decision. No full production theme or navigation redesign is claimed.
